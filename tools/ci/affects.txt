# Which files each CI test depends on (tools/ci/affected.sh): on a pull
# request, a test runs only if a changed file starts with one of its paths;
# otherwise it finishes green at once ("not touched").
#
#   <test> <path prefix>...      (one or more lines per test)
#   * <path prefix>...           paths every test depends on
#
# Safe defaults: a test with no line here always runs, and so does every
# test when a changed file matches no line at all (docs and *.md aside).
# On channel branches (pushes) every test always runs.
